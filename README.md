# ContextFlow — демки ветвящихся диалогов

Каждая демка = партия из 3 сцен. Внутри — живой движок: свободный ответ,
ветки, переспрашивание, кнопка «Не знаю». Открой файл в браузере и говори/пиши
своими словами: ответишь иначе — собеседник ответит иначе.

Эти же данные 1-в-1 лежат в приложении (js/lessons.js), идентичность
проверяется автотестами (сейчас 507/0).

| файл | партия | сцены |
|---|---|---|
| демо-5 | 1 | Первое приветствие · Заполнить анкету · Разговор о семье |
| демо-6 | 2 | Назвать количество · Выбрать цвет · Назначить день |
| демо-7 | 3 | Узнать время · Разговор о погоде · У врача |
| демо-8 | 4 | Купить куртку · Заказать обед · У барной стойки |
| демо-9 | 5 | Показать квартиру · Что-то сломалось · Найти банк |
| демо-10 | 6 | Купить билет · Объяснить дорогу · Рассказать о работе |
| демо-11 | 7 | На языковых курсах · Оплата на кассе · Открыть счёт |
| демо-12 | 8 (боль релоканта) | В аптеке · Регистрация после приезда · СИМ-карта и контракт |
| демо-13 | 9 | Перевод денег · Проблема с интернетом · Не расслышал |

`демо-5-тест.js` — ранний автотест первой партии (исторический; актуальный
регресс живёт в основном репозитории: `qa/flow-test.js`).

Демки собираются генератором из кода приложения:
`node qa/build-demo.js <файл> <№ партии> <сцена1> <сцена2> <сцена3>`.
Править демки руками не нужно — правь сцены в приложении и пересобирай.

## Закрытие баглиста D6 — актуально на HEAD main (коммит выше)

Если твой снапшот старше этого блока — возьми свежий клон; всё проверено на HEAD.

| пункт | фраза | ветка на HEAD |
|---|---|---|
| D6-001 | I do not need five. | many (не five) |
| D6-002 | I don't need anything more. | all |
| D6-003 | I will not wait for your call. | refuse |
| D6-004 | Not Thursday, Friday works. | oth (не thu) |
| D6-005 | Not Wednesday, Thursday. | direct, день = thursday |
| D6-006 | No card, cash please. | cash (обе сцены оплаты) |
| D6-007 | No, when will I know? | ask |
| D6-008 | I am not sure, medium. | m |
| D6-009 | didn't/wasn't/… в EXP | есть (ядро демо = ядро приложения) |
| D6-010 | Not black. Red one. | red |

Системно: ядро всех демок (5–13) собирается из актуальных хелперов приложения
(app.js + lessons.js); застарелое ядро из шаблона больше не используется.
